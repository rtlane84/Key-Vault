Project Refactor Request

Refactor this existing project into a production-ready single-user digital product and license key fulfillment platform.

The goal is to sell digital products and license keys through:

* My own website
* eBay

and automatically deliver license keys after successful payment.

The application should be deployable to:

* Vercel
* Supabase PostgreSQL
* Stripe
* Resend

Replit should only be used for development and testing.

⸻

Core Requirements

Convert the current project into a single-user application.

Remove:

* Multi-tenancy
* SaaS subscriptions
* Team/organization features
* Customer account management unless required for checkout
* Replit-specific deployment assumptions

Keep:

* Product management
* License key inventory
* Order management
* Fulfillment logs
* Admin dashboard
* eBay integration architecture
* Duplicate fulfillment protection

Refactor existing code whenever possible instead of rebuilding from scratch.

⸻

Shared Inventory

License key inventory must be shared across all sales channels.

Example:

Website sale:

* Uses inventory from Product A

eBay sale:

* Uses inventory from Product A

Both sales channels consume keys from the same inventory pool.

Never allow the same key to be delivered twice.

Stripe Integration

Use Stripe Checkout.

Admin workflow:

1. Create product in Stripe
2. Create price in Stripe
3. Copy Stripe Price ID into product

Customer workflow:

1. Click Buy
2. Redirect to Stripe Checkout
3. Pay
4. Return to success page

Stripe Webhooks:

Create webhook endpoint.

On successful payment:

* Verify webhook signature
* Create order
* Match product
* Assign next unused key
* Mark key assigned
* Email customer
* Create fulfillment log
* Prevent duplicate fulfillment

Handle Stripe webhook retries safely.

Product Mapping

Products should have internal SKUs.

eBay listings should be mapped using SKU whenever possible.

Automatic Mapping:

If:

eBay SKU = WIN11PRO

and

Product SKU = WIN11PRO

Automatically map them.

If no match exists:

Mark listing as Unmapped.

Allow manual mapping override.

Allow remapping anytime.
